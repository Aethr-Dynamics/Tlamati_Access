# Historia 01-H1 - Definir Roles Estudiantiles

## Descripción
Como Administrador,
Quiero definir los roles de usuario para la comunidad estudiantil (ej. Estudiante Regular, Estudiante Investigador, etc.)
Para poder gestionar adecuadamente los permisos y funcionalidades dentro del sistema.

---

## Story Points

5

---

## Criterios de aceptación

- [ ] Se definen al menos 3 roles de usuario diferentes: Estudiante Regular, Estudiante Investigador, Estudiante con beca.
- [ ] Cada rol tiene un conjunto de permisos asignados (ej. acceso a ciertos recursos, capacidad para generar informes).
- [ ] La definición de roles se documenta en la documentación del sistema.
