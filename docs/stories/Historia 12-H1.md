# Historia 12-H1 - Desarrollo App Móvil

## Descripción

Como Desarrollador,
Quiero desarrollar una app móvil que solo ingresará un miembro de la comunidad.
Para facilitar el acceso a los servicios desde dispositivos móviles.

---

## Story Points

5

---

## Criterios de aceptación

- [ ] Se desarrolla una aplicación móvil para Android o iOS.
- [ ] La aplicación permite al usuario ingresar con sus credenciales: Correo electrónico institucional, y Contraseña fuerte.
- [ ] Se implementa un sistema de validación de contraseñas (ej. longitud mínima, caracteres especiales).
