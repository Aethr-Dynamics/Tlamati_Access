# Historia 02-H1 - Definir Roles Trabajadores

## Descripción

Como Administrador,
Quiero definir los roles de usuario para la comunidad trabajadora (ej. Personal Administrativo, Supervisor de Seguridad, etc.)
Para poder gestionar adecuadamente los permisos y funcionalidades dentro del sistema.

---

## Story Points

5

---

## Criterios de aceptación

- [ ] Se definen al menos 3 roles de usuario diferentes: Personal Administrativo, Supervisor de Seguridad, Técnico de Mantenimiento. 
- [ ] Cada rol tiene un conjunto de permisos asignados (ej. acceso a ciertas áreas, capacidad para generar informes).
- [ ] La definición de roles se documenta en la documentación del sistema.
