# Historia 36-H1 - Registrar Menor de Edad

## Descripción

Como Personal de Seguridad,
Quiero que el sistema registre a un visitante menor de edad.
Para asegurar la seguridad y control del menor de edad en el plantel educativo.

---

## Story Points

5

---

## Criterios de aceptación

- [ ] Se implementa una funcionalidad para registrar visitantes menores de edad.
- [ ] Se omite el campo de identificación oficial del menor de edad.
- [ ] En el motivo de visita, se indica que es un menor de edad y que viene acompañado de un tutor.
- [ ] Al tutor se le imprime el QR.
- [ ] El menor no recibe el QR.

- Ninguna
