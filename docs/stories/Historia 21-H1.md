# Historia 21-H1 - Registrar Entrada/Salida con Verificación    

## Descripción

Como Personal de Seguridad,
Quiero que el sistema registre la entrada y salida del miembro, y verifique si llego antes de la hora establecida, o llego tarde.
Para controlar el acceso al plantel educativo.

---

## Story Points

5

---

## Criterios de aceptación

- [ ] Se implementa un sistema que registra las entradas y salidas de los miembros.
- [ ] El sistema verifica si el miembro llegó antes o después de su hora de entrada programada.
- [ ] Se genera una alerta en caso de retraso.
