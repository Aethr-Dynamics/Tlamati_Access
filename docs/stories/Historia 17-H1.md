# Historia 17-H1 - Registrar Reconocimiento Facial Web

## Descripción

Como Servicio Escolar,
Quiero al sistema web, apartado opcional para registrar y activar el reconocimiento facial de un miembro.
Para agilizar el proceso de acceso a los servicios.

---

## Story Points

5

---

## Criterios de aceptación

- [ ] Se implementa una interfaz en el sistema web que permite al personal escolar registrar y activar el reconocimiento facial de un miembro.
- [ ] La activación se realiza mediante la captura de una fotografía del rostro del miembro.
- [ ] Se guarda la información del miembro en la base de datos, junto con los datos del reconocimiento facial.
