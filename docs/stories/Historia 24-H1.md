# Historia 24-H1 - Establecer Horario (Administración) 

## Descripción

Como Administrador,
Quiero establecer el horario de entrada y salida de un miembro trabajador.
Para controlar el tiempo de acceso al plantel educativo.

---

## Story Points

5

---

## Criterios de aceptación

- [ ] Se implementa una interfaz en el sistema que permite al personal administrativo establecer el horario de entrada y salida de un miembro.
- [ ] El horario se guarda en la base de datos, junto con los datos del miembro.
