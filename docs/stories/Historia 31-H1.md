# Historia 31-H1 - Verificar Registro QR

## Descripción

Como Personal de Seguridad,
Quiero comprobar si el código QR se encuentra registrado en la base de datos de la comunidad, o en la de visitantes.
Para verificar la identidad del visitante y facilitar el acceso al plantel educativo.

## Criterios de aceptación

- [ ] La funcionalidad devuelve un resultado indicando si el código QR está registrado o no.
