# Historia 20-H1 - Agregar/Eliminar Huella Dactilar

## Descripción

Como Servicio Escolar,
Quiero integrar al sistema, apartado para agregar o eliminar una huella dactilar de un miembro.
Para gestionar las huellas dactilares de los miembros.

---

## Story Points

5

---

## Criterios de aceptación

- [ ] Se implementa una interfaz en el sistema que permite al personal escolar agregar o eliminar huellas dactilares de un miembro.
- [ ] La adición/eliminación se realiza mediante la captura de la huella dactilar del miembro.
- [ ] Se guarda la información de la huella dactilar en la base de datos, junto con los datos del miembro.
