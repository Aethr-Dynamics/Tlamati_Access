# Historia 30-H1 - Escanear QR Visitante

## Descripción

Como Personal de Seguridad,
Quiero escanear un código QR de un visitante.
Para verificar la identidad del visitante y facilitar el acceso al plantel educativo.

## Story Points

2

## Criterios de aceptación

- [ ] Al escanear el código QR, se obtiene la información del usuario (Nombre completo, matricula o identificador, grupo de pertenencia).
