# Historia 11-H1 - Registrar Nuevo Miembro

## Descripción

Como Administrador,
Quiero un sistema para registrar a un nuevo miembro a la comunidad.
Para agregar nuevos miembros al sistema y facilitar su acceso a los servicios.

---

## Story Points

5

---

## Criterios de aceptación

- [ ] Se presenta un formulario web con los campos obligatorios: Nombre completo, Año de nacimiento, Sexo (Femenino, Masculino), Grupo de pertenencia.
- [ ] Se solicita una fotografía del rostro del nuevo miembro.
- [ ] Al completar el formulario, se guarda la información en la base de datos.
