# Historia 03-H1 - Registrar Visitas Web

## Descripción

Como Personal de Seguridad,
Quiero registrar a un visitante en el sistema web, solicitándole los datos de Nombre, Motivo de visita y Tiempo que estará dentro del plantel.
Para tener un registro formal de la visita y poder realizar un seguimiento.

---

## Story Points

2

---

## Criterios de aceptación

- [ ] Se presenta un formulario web con los campos obligatorios: Nombre, Motivo de visita (con opciones predefinidas), Tiempo estimado de estancia.
 
 
- [ ] Al completar el formulario, se genera un registro en el sistema con la información ingresada.
- [ ] El sistema valida que todos los campos obligatorios estén completos antes de guardar el registro.
