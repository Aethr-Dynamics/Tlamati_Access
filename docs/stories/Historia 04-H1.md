# Historia 04-H1 - Generar QR Único

## Descripción

Como Personal de Seguridad,
Quiero que al registrar a un visitante se genere un QR único.
Para facilitar el acceso y control del visitante.

## Criterios de aceptación

- [ ] Al completar el registro de un visitante, el sistema genera automáticamente un código QR único.
 
 
- [ ] El código QR es legible por el lector de códigos QR.
- [ ] El código QR se imprime en un formato adecuado para su uso (ej. etiqueta).
