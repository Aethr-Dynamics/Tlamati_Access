# Historia 07-H1 - Historial Completo de Visitantes

## Descripción

Como Administrador,
Quiero poder ver todo el historio de visitantes.
Para realizar análisis exhaustivos y generar informes detallados.

---

## Story Points

5

---

## Criterios de aceptación

- [ ] Se implementa una vista que muestra todos los registros de visitantes desde su creación hasta la fecha actual.
- [ ] El administrador tiene acceso a esta vista.
- [ ] La vista permite filtrar por fecha, nombre o motivo de visita.
- [ ] La vista permite exportar los datos en formato CSV o Excel.
