# Historia 02-H2 - Asignar Roles a Usuarios

## Descripción

Como Administrador,
Quiero poder asignar los roles definidos a los usuarios que pertenecen a la comunidad trabajadora.
Para asegurar que cada usuario tenga el nivel de acceso apropiado al sistema.

## Story Points

3

## Criterios de aceptación

- [ ] Se implementa una interfaz para asignar roles a usuarios existentes.
- [ ] La asignación de roles se refleja en el sistema (ej. cambios en los permisos).
- [ ] Se registra la asignación de roles en un log de auditoría.
